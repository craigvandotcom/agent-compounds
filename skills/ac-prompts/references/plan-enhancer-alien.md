# Plan Enhancer Alien

First read the plan document carefully and understand its goals and intended implementation. Then think like a genius systems architect: how could this be elevated to exceptional quality while preserving the original intent?

Generate 20+ enhancement ideas across these vectors:

**Quality Elevation:**

- Formal invariants and provable correctness guarantees
- Adaptive fault-tolerance and graceful degradation
- Self-evolving modularity (components that adapt to usage)
- Comprehensive error handling with recovery paths

**User Experience Excellence:**

- Predictive empathy (anticipatory UIs, context-aware affordances)
- Accessibility across sensory modalities
- Multi-modal adaptations (voice, gesture, visual)
- Neuro-symbolic interaction patterns

**Performance Beyond Standard:**

- Entropic compression techniques
- Spectral decompositions for data optimization
- Holographic caching and probabilistic data structures
- Asymptotic complexity improvements

**Holistic System Thinking:**

- Meta-learning for feature evolution over time
- Ethical constraints (value-aligned design, deontic logics)
- Pragmatic complexity justification (only add what matters)
- Long-term maintainability and extensibility

**Equivalence Preservation:**

- Original intent must remain intact
- Prove fidelity through equivalence mappings
- Enhancements add capability, never subtract or change core goals

Rank all candidates by: (Impact × Confidence) / Effort

Winnow to the top 5, ordered best to worst. For each:

- What it enhances and why it matters
- Concrete implementation approach
- Trade-offs and potential downsides
- Confidence level (0-100%)

## Output Format

### Step 1: Auto-Apply Critical Enhancements

Identify enhancements that are non-negotiable improvements (clear quality wins, obvious UX improvements, proven performance gains). Immediately apply these without asking.

### Step 2: Present Remaining Enhancements Ranked by Priority

Display in this order (low first, critical last) so most important items appear closest to the selection prompt:

```markdown
## Low Priority

1. **[Title]** - [Enhancement Type] - Location: `section/component`
   - Enhancement: [What it improves]
   - Approach: [How to implement]
   - Trade-offs: [Potential downsides]
   - Confidence: [0-100%]

## Medium Priority

1. **[Title]** - [Enhancement Type] - Location: `section/component`
   - Enhancement: [What it improves]
   - Approach: [How to implement]
   - Trade-offs: [Potential downsides]
   - Confidence: [0-100%]

## High Priority

1. **[Title]** - [Enhancement Type] - Location: `section/component` [Impact: X, Confidence: Y, Effort: Z]
   - Enhancement: [What it improves]
   - Approach: [How to implement]
   - Trade-offs: [Potential downsides]
   - Confidence: [0-100%]

## Critical (Auto-Applied)

1. [Description of enhancement applied] - Location: `section/component`
```

### Step 3: Ask User Which to Apply

```
Which enhancements would you like to apply?
Options:
- "all" - Apply all proposed enhancements
- "critical and high" - Apply critical + high priority
- "only [N, M]" - Apply only specific enhancement numbers
- "none" - Skip remaining enhancements (critical already applied)
```

### Step 4: Apply Selected Enhancements and Output Enhanced Plan

Execute the selected enhancements, then output the complete enhanced plan with improvements integrated.
